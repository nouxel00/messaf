# demo

Les données de démonstration sont toutes fictives et se chargent au premier démarrage, sans script à lancer :

- les 11 comptes, leurs rôles et leurs attributs : `deploy/keycloak/realm-messaf.json` ;
- l'organigramme du ministère de la Santé, ses postes et les affectations : `api/messaf_api/demo.py` (réglage `MESSAF_DEMO=1`) ;
- deux salons de fonction : créés par le bot de fonction à la demande de l'API.

Le script de la vidéo de démonstration suit la même distribution de rôles.
